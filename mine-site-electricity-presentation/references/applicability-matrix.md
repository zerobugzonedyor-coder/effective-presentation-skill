# 规范适用性判定表（范围已收窄）

本 Skill 仅使用以下标准：
- GB 55034-2022
- JGJ/T 46-2024
- GB 50194-2014
- JGJ 59-2011
- DL 5009.3-2013

已明确剔除矿山专用标准（GB 16423、GB 50070）及新版电力建设规程（DL/T 5009.3-2026）。

## 判定表模板

| 判断项 | 应记录的内容 |
|--------|--------------|
| 区域 | 房建施工区 / 变电站施工区 / 交界区 / 生活区 |
| 作业活动 | 临时配电、设备检修、临近带电作业等 |
| 设备与供电系统 | 电压等级、供电方式、发电机配置等 |
| 适用规范清单 | 从本 Skill 限定的五本标准中选择 |
| 适用理由 | 为什么该标准适用于当前对象 |
| 边界与例外 | 不适用的部分、特殊条件 |
| 责任人 | 谁负责确认本次适用性 |
| 判定日期 | 本次判定时间 |

## 默认边界指引（仅供参考）

| 场景 | 核心依据（方向） | 叠加依据 | 注意事项 |
|------|------------------|----------|----------|
| 房建临时用电 | GB 55034-2022、JGJ/T 46-2024、GB 50194-2014 | — | 不得继续使用已废止的 JGJ 46-2005 |
| 变电站施工/改扩建 | 上述建筑标准 | DL 5009.3-2013 | 带电隔离、监护要求突出；不引用新版 DL/T 5009.3-2026 |
| 生活区/宿舍用电 | GB 55034-2022 等 | 项目管理制度 | 大功率电器、插座串联是高频风险点 |
| 交界区域 | 按实际作业归属与供电系统判定 | 可能同时适用多本标准 | 必须明确责任主体与适用清单 |

## 使用规则
- 不得输出超出本 Skill 限定标准范围的结论。
- 必须结合具体作业活动、设备与供电系统做判断。
- 判定结果应在汇报或检查记录中可追溯。
