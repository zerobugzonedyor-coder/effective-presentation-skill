# 规范适用性判定表

在生成任何涉及跨区域或跨专业的内容前，必须先完成适用性判断。

## 判定表模板

| 判断项 | 应记录的内容 |
|--------|--------------|
| 区域 | 房建施工区 / 矿山生产区 / 变电站区 / 交界区 / 生活区 |
| 作业活动 | 临时配电、设备检修、临近带电作业、爆破区附近作业等 |
| 设备与供电系统 | 电压等级、供电方式、是否一级负荷、发电机配置等 |
| 适用规范清单 | 经核验的标准编号与版本 |
| 适用理由 | 为什么该标准适用于当前对象 |
| 边界与例外 | 不适用的部分、特殊条件、需叠加的标准 |
| 责任人 | 谁负责确认本次适用性 |
| 判定日期 | 本次判定时间 |

## 默认边界指引（仅供参考，最终以项目实际与正式文本为准）

| 场景 | 核心依据（方向） | 叠加依据（方向） | 注意事项 |
|------|------------------|------------------|----------|
| 房建临时用电 | GB 55034-2022、JGJ/T 46-2024、GB 50194-2014 | — | 不得继续使用已废止的 JGJ 46-2005 |
| 矿山生产区域或邻近爆破区/采空区 | 上述建筑标准 | GB 16423-2020（必要时 GB 50070-2020） | 负荷等级、供电可靠性、工作票需单独判断 |
| 变电站施工/改扩建 | 上述建筑标准 | DL 5009.3-2013（至2026-12-25）或 DL/T 5009.3-2026（自2026-12-26） | 带电隔离、监护、验电接地要求突出 |
| 生活区/宿舍用电 | GB 55034-2022 等 | 项目管理制度 | 大功率电器、插座串联是高频风险点 |
| 交界区域 | 按实际作业归属与供电系统判定 | 可能同时适用多套要求 | 必须明确责任主体与适用清单 |

## 使用规则
- 不得简单写“房建按建筑标准、矿山叠加矿山标准”就结束。
- 必须结合具体作业活动、设备与供电系统做判断。
- 判定结果应在汇报或检查记录中可追溯。
