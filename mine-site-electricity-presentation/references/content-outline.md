# 内容大纲与关键要求摘录

## 第一章 规范体系

### 1.1 强制性国家标准
- GB 55034-2022《建筑与市政施工现场安全卫生与职业健康通用规范》
  - 全部条文强制执行
  - 覆盖接地防雷、配电线路、剩余电流保护、照明、检修停电、有限空间用电

### 1.2 临时用电与供用电标准
- JGJ/T 46-2024《建筑与市政工程施工现场临时用电安全技术标准》
  - 2025-01-01起实施，替代 JGJ 46-2005
- GB 50194-2014《建设工程施工现场供用电安全规范》
  - 适用于10kV及以下供用电设施全链条

### 1.3 电力建设标准
- DL 5009.3-2013（2026-12-25前仍可使用）
- DL/T 5009.3-2026（2026-12-26起实施，全部替代）

### 1.4 矿山相关标准
- GB 16423-2020《金属非金属矿山安全规程》
- GB 50070-2020《矿山电力设计标准》（补充）

### 1.5 检查框架
- JGJ 59-2011《建筑施工安全检查标准》（检查表框架，判定以现行强制规范为准）

## 第二章 强制性核心要求

### 2.1 临时用电管理
- 设备≥5台或总容量≥50kW → 必须编制临时用电施工组织设计
- 电工持证上岗，非电工禁止电气作业
- 建立巡检、维修、验收、接地电阻与漏保测试记录

### 2.2 配电系统底线
- 必须 TN-S 三相五线制，N与PE严格分开
- 三级配电、二级剩余电流保护
- PE线严禁装开关/断路器/熔断器，严禁通过工作电流，严禁断线
- 发电机与市电必须闭锁，严禁并列

### 2.3 配电箱、电缆与设备
- 每台设备专用开关箱，严禁一箱多控
- 电缆必须含全部工作导体+PE线；N淡蓝、PE黄绿双色
- 电缆禁止拖地、泡水、碾压；埋地需保护层+套管
- 配电箱防雨防尘上锁，N/PE端子板分设

### 2.4 接地、防雷、外电
- 重复接地、设备接地、防雷接地符合限值
- 塔吊、施工升降机等高大设备必须防雷接地
- 外电线路下方禁止临建、堆料、作业；安全距离不足必须绝缘隔离

### 2.5 照明与检修
- 手持灯具≤36V；金属容器/特别潮湿场所更低电压
- 必须使用双绕组安全隔离变压器，严禁自耦
- 检修严禁带电作业，严禁预约停送电
- 易燃易爆、潮湿环境严格执行停电-验电-隔离-挂牌-上锁

### 2.6 矿山与变电站特殊要求
- 矿山：一级负荷双重电源、井下电压、IT/TN-S、漏电保护、阻燃电缆、电气硐室、工作票
- 变电站：带电区隔离、试验、改扩建隔离、停电作业、验电接地、监护

## 第三章 雷点与争议

### 3.1 高频雷点（必须逐条对应正确做法）
- 仍执行旧版 JGJ 46-2005
- 未编制临电方案或方案与现场不符
- TN-S不彻底（N/PE混接、PE压在箱体螺母）
- 未形成三级配电二级漏保或参数不合规
- 一闸多机、一箱多控、私拉乱接
- 电缆拖地/浸水/无套管/被碾压
- 配电箱无锁、无标识、接线混乱
- 塔吊/升降机接地防雷未验收
- 潮湿/管沟/金属容器未用安全电压
- 宿舍大功率电器、插座串联、无漏保
- 变电站改扩建未隔离带电设备
- 矿山爆破区/采空区用电、停送电管理不规范

### 3.2 主要争议与统一口径
- JGJ/T 46-2024 与旧版口径不一致 → 统一按2024版
- GB 50194 与 JGJ/T 46 关系 → 同时执行
- DL 5009.3 过渡期 → 2026-12-26必须切换
- 矿山房建边界 → 房建本体按建筑标准，进入矿山区域叠加 GB 16423
- JGJ 59 与 GB 55034 → JGJ 59作框架，判定以强制规范为准

### 3.3 执行建议
先划分边界：房建临时用电 / 矿山区域用电 / 变电站施工用电  
核心三件套：GB 55034-2022 + JGJ/T 46-2024 + GB 50194-2014
