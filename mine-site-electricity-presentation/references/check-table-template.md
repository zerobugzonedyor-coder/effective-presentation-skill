# 施工用电安全检查表模板（可复现版）

> 本模板用于支持现场检查，而非仅作培训示例。  
> 每条检查项应能追溯到 technical-requirements.md 中的结论 ID 或风险 ID。

## 1. 标准字段（推荐完整版）

| 字段 | 说明 |
|------|------|
| 检查项编号 | 唯一编号，便于闭环 |
| 结论/风险 ID | 对应 ELEC-xxx 或 RISK-xxx |
| 检查项目 | 简要名称 |
| 检查对象 | 区域/配电箱/设备/线路编号 |
| 检查内容 | 具体要看什么 |
| 检查方法 | 目视 / 测量 / 查阅记录 / 试验 等 |
| 判定标准 | 符合什么条件算“符合” |
| 规范依据 | 标准编号 + 条款（若已核验）或标注待核验 |
| 检查结果 | 符合 / 不符合 / 不涉及 / 无法判定 |
| 问题描述 | 具体位置、现象、照片/附件编号 |
| 风险等级 | 由项目制度或适用规范确定（禁止AI自行编造统一标准） |
| 是否需立即停工/控制 | 是/否 + 临时措施 |
| 整改要求 | 可验证、有时限 |
| 责任人 | 整改责任人 |
| 整改期限 | 日期 |
| 复查人 | — |
| 复查结果 | — |
| 证据附件 | 照片、测试记录、方案编号等 |

## 2. 最小可用字段（若现场表格受限）
检查项编号 | 结论ID | 检查对象 | 检查内容 | 检查方法 | 检查结果 | 问题描述 | 整改要求 | 责任人 | 复查结果

## 3. 示例检查条目（均带状态提示）

### 示例 A（对应 ELEC-001）
- **检查内容**：是否编制临时用电施工组织设计并完成审批
- **检查方法**：查阅方案文件、审批记录，对照现场设备数量与容量
- **判定标准**：达到标准规定门槛时有经审批的方案，且与现场基本一致
- **规范依据**：JGJ/T 46-2024、GB 55034-2022（具体条款待核验）
- **状态提示**：门槛数值与审批要求以正式文本为准

### 示例 B（对应 ELEC-003）
- **检查内容**：是否采用 TN-S 系统，N 线与 PE 线是否分开
- **检查方法**：目视端子排、色标、连接方式；必要时查阅系统图
- **判定标准**：N 与 PE 在规定点分开，无混接、无错误压接
- **规范依据**：JGJ/T 46-2024 等（条款待核验）
- **状态提示**：系统形式的强制范围需确认

### 示例 C（对应 ELEC-006）
- **检查内容**：每台设备是否有专用开关箱，是否存在一箱多控
- **检查方法**：现场逐台核对开关箱与设备对应关系
- **判定标准**：一机一闸一箱（或标准允许的等效方式）
- **规范依据**：JGJ/T 46-2024（条款待核验）

### 示例 D（对应 RISK-004 / ELEC-007）
- **检查内容**：电缆是否存在拖地、浸水、无保护穿越道路、被碾压等情况
- **检查方法**：沿线目视检查 + 关键部位拍照
- **判定标准**：无明显机械损伤与浸泡；通行区域有保护措施
- **类型**：现场风险提示 + 待核验正式要求
- **说明**：发现明显危险可立即要求整改；正式合规判定还需结合敷设方式与绝缘状态

### 示例 E（对应 ELEC-009）
- **检查内容**：潮湿场所、金属容器、有限空间照明是否采用安全电压
- **检查方法**：查看灯具铭牌与供电装置类型
- **判定标准**：符合对应场所的安全特低电压及隔离要求
- **规范依据**：GB 55034-2022、JGJ/T 46-2024（不同场所限值待分别核验）
- **注意**：不同场景限值与装置要求可能不同，不得混用同一标准

### 示例 F（对应 ELEC-013）
- **检查内容**：变电站区域是否设置带电隔离、警戒和监护
- **检查方法**：现场核查隔离措施、警示标志、监护人配置与记录
- **判定标准**：符合适用电力建设安全工作规程要求
- **规范依据**：DL 5009.3-2013 或 DL/T 5009.3-2026（按实施日期选择，条款待核验）

## 4. 使用与维护规则
- 检查结果为“无法判定”时，必须记录原因（缺图纸、缺测试仪器、缺标准文本等）。
- 风险等级与是否停工，必须依据项目管理制度或适用规范，禁止由模型自行统一规定。
- 标准版本变更后，应更新受影响检查项，并保留变更记录。
- 本模板输出前，应对照 technical-requirements.md 确认引用的 ID 状态。
