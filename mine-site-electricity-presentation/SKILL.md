# 矿山工业场地房建项目施工用电规范解读与现场检查要点

本 skill 在 effective-presentation 核心原则之上，针对**施工用电**专题做深度适配。  
目标：让听众（项目经理、安全总监、电工班组、监理）真正理解“必须做到什么、现场最容易踩的坑、如何检查整改”，并知道下一步行动。

## 核心原则（继承 + 强化）

1. **One idea per slide** — 每页只讲一个结论，严禁把多个规范或雷点堆在一页。
2. **Action titles** — 标题必须是完整断言句，能独立讲清“所以然”。  
   - 坏标题：临时用电管理  
   - 好标题：临时用电设备≥5台或总容量≥50kW时必须编制临电施工组织设计
3. **Ghost-deck 测试** — 只读所有标题，完整论证链必须清晰成立。
4. **聚焦用电主线** — 绝不展开消防、高处、起重等非用电内容。
5. **密度匹配场景** —  
   - 现场培训 / 班组交底：稀疏、大字、视觉优先  
   - 项目部 / 公司汇报：中等密度，可扫读  
   - 留档检查表：可 denser，但字段清晰

## 固定汇报结构（4章12节）

**汇报题目**  
矿山工业场地房建项目施工用电规范解读与现场检查要点

### 第一章 项目施工用电规范体系（解决“依据哪些规范？”）
- 1.1 强制性国家标准（GB 55034-2022）
- 1.2 施工现场临时用电与供用电标准（JGJ/T 46-2024 + GB 50194-2014）
- 1.3 电力建设相关用电标准（DL 5009.3-2013 / DL/T 5009.3-2026）
- 1.4 矿山项目用电相关标准（GB 16423-2020 + GB 50070-2020）
- 1.5 检查框架标准（JGJ 59-2011）

### 第二章 强制性条文与临电核心要求（解决“必须做到什么？”）
- 2.1 临时用电管理底线
- 2.2 配电系统底线要求（TN-S + 三级配电二级漏保）
- 2.3 配电箱、电缆与设备用电
- 2.4 接地、防雷与外电防护
- 2.5 照明、特殊环境与检修停电
- 2.6 矿山与变电站特殊用电要求

### 第三章 现场执行雷点、争议点与注意事项（解决“最容易错在哪？”）

- 3.2 主要规范争议与口径统一
- 3.3 执行建议与边界划分

### 第四章 施工用电安全检查表（解决“如何检查与闭环？”）
- 4.1 检查表按用电系统链条分类（11类）
- 4.2 检查表标准字段
- 4.3 关键检查条目示例

## 最终收束口径（必须出现）

> 本项目施工用电以 **GB 55034-2022、JGJ/T 46-2024、GB 50194-2014** 为核心依据；安全检查以 **JGJ 59-2011** 为框架；涉及变电站施工用电时，2026-12-25前执行 **DL 5009.3-2013**，2026-12-26起执行 **DL/T 5009.3-2026**；涉及矿山区域用电时，同步执行 **GB 16423-2020**。

## 生成PPT时的强制工作流

1. 先输出完整 **Ghost-deck（仅标题序列）**，确认故事线通顺后再生成内容页。
2. 每页标题必须是断言句，带规范编号。
3. 雷点页用“问题 → 后果 → 正确做法”三段式，避免纯罗列。
4. 检查表页优先用表格或卡片，字段清晰。
5. 结尾页必须给出“下一步行动”和责任边界。
6. 严格遵守 one-idea-per-slide，宁可多页也不堆叠。
