# Effective Presentation

Apply research-backed principles from Nancy Duarte (Slide:ology / Resonate), the PLOS Computational Biology "Ten simple rules for effective presentation slides", assertion-evidence research, and Guy Kawasaki 10/20/30 rule. Goal is not decorative slides but decks that audiences actually understand, remember, and act on.

## Core Principles (non-negotiable)

1. **One idea per slide**  
   Every slide has exactly one central message. Split aggressively. A 20-minute talk ≈ 15–25 focused slides.

2. **Action titles (Assertion-Evidence)**  
   Title is a full sentence stating the takeaway, not a topic label.  
   - Bad: "Results"  
   - Good: "Treatment effect is significant across all three cohorts"  
   Ghost-deck test: reading only the titles in sequence must tell the complete argument.

3. **Match density to context**  
   - Live delivery / keynote / all-hands → sparse, visual, cinematic (slides amplify the speaker).  
   - Pre-read / exec briefing / report → denser but still scannable (slide-docs that stand alone).  
   Never force one style on every situation.

4. **Minimize cognitive load**  
   Audience cannot read dense text and listen at the same time. Text is a signpost, not the script. Prefer visuals + spoken narrative. Limit to ≤4–6 elements per slide. Generous whitespace.

5. **Story structure first**  
   Before opening PowerPoint, define:  
   - Audience (who is the hero?)  
   - Ordinary world + problem  
   - Threshold / decision moment  
   - New world / call to action  
   Use SCQA, problem-solution-benefit, or Hero’s Journey as needed.

## Workflow

1. Clarify audience, desired action, and one big idea.
2. Outline the narrative spine (titles only) as a sequence of assertions.
3. For each assertion, choose the single best visual or evidence.
4. Build slides last. Apply the density rule for the delivery context.
5. Rehearse transitions, not individual slides. Time ≈ 1 minute per slide.
6. Run the ghost-deck test and the “so what?” filter on every slide.

## Design Rules

- Font ≥ 24–30 pt for body; titles larger and dominant.
- Max 2 typefaces. High contrast. Limited palette (60-30-10).
- One chart or primary visual per content slide.
- Avoid bullet lists when possible; if used, ≤4–5 short items.
- No decorative animations or stock-photo wallpaper.
- Cite sources inline when evidence matters.
